# 🌌 Vybgen

Your AI-powered Solana trading companion, providing real-time market insights, wallet analysis and more 

[![Telegram Bot](https://img.shields.io/badge/Telegram-@vybgen__bot-blue?style=flat&logo=telegram)](https://t.me/vybgen_bot)

## 🚀 Features

### 💰 Wallet Analysis
- **Token Balance Scan** (`/tb [address]`) - Get detailed token holdings and values
- **NFT Collection Analysis** (`/nb [address]`) - View NFT collections and their values
- **Profit & Loss Metrics** (`/pnl [address]`) - Track your trading performance
- **Portfolio Management** (`/portfolio`) - Manage and track your digital assets

### 🔍 Token Research
- **Token Deep Dive** (`/s [mint]`) - Comprehensive token analysis and metrics
- **Whale Watch** (`/whale [mint]`) - Monitor top token holders
- **Price Charts** (`/c [mint]`) - Visualize token price movements
- **Token Leaderboard**(`/lb`) - Get Leaderboard of tokens

### 📰 Market Intelligence
- **Market News** (`/markets`) - Stay updated with global market news
- **Crypto News** (`/crypto`) - Get the latest crypto-specific updates

### 💃 Fun & Entertainment
- **Wallet Roast** (`/roast [address]`) - Get a humorous analysis of wallet performance
- **Motivation** (`/motivate`) - Get trading motivation when needed
- **Markets** (`/markets`) - Get global market status
- **News** (`/news`) - Get global and crypto news 


## 🛠️ Quick Actions
- Use `/s` to search for tokens
- Use `/c` to view price charts
- Use `/whale` to track big players
- Use `/tb` to check wallet balances
- Use `/nb` to view NFT collections
